# Emerald Moon

Отдельный mobile-first шаблон свадебного приглашения в стилистике ночного сада: фиксированный лунный фон, тёплые фонари, изумрудное стекло и объёмный декор с прозрачным фоном.

- ID приглашения берётся из первого сегмента URL: `/3` → `3`.
- Данные загружаются через существующий API `GET /priglosi/{id}`.
- RSVP сохраняется существующим способом: свежий `GET`, добавление гостя и `PATCH /priglosi/{id}/full`.
- Поддерживаются русский, кыргызский и казахский языки, карты, тайминг, календарь и обратный отсчёт.
- Фоновое видео без звука; при `prefers-reduced-motion` показывается статичный постер.
- В итоговой сборке оставлены 4 оптимизированных декоративных PNG с альфа-каналом.

Локальный запуск:

```powershell
node scripts/serve.mjs
```

Открыть: `http://127.0.0.1:4182/3`.

Для Vercel настроена публикация каталога `dist` с поддержкой динамических адресов приглашений.
